# Changelog

## 0.5.0

- Add a role-aware Overview as the default landing page, with quick links, actionable orders and out-of-stock products.
- Add native-permission Reports: date presets/custom range, net sales, refunds, daily chart, order statuses, product rankings and accessible daily figures.
- Process orders in bounded, authenticated batches using WooCommerce CRUD for HPOS and legacy stores. Keep incomplete totals hidden and document timezone, refund and currency semantics.
- Add Persian translations and checks for financial calculations, pagination, DST and role/ownership boundaries.

## 0.4.0

- Add general, reading, discussion and media settings with native permissions and stale-form checks.
- Add user creation, editing, permitted role assignment and password-reset links, plus personal profile, email confirmation and password changes.
- Add comment moderation and replies, category and tag management, and classic and block navigation with hierarchy and ordering.
- Add site-health checks and confirmed WordPress privacy exports and erasure with paginated plugin processors.
- Allow accounts with WordPress read access to manage their own profile.

## 0.3.0

- Add Posts, Pages and Media sections within the Dexo workspace.
- Create simple content, edit titles and publication status, upload images or PDFs, and edit media descriptions.
- Apply native WordPress record-level capabilities and preserve existing block or custom-markup content through the WordPress editor link.

## 0.2.0

- Bring the original light store workspace to Dexo, including the sidebar, top bar, lists, record dialogs and two-column sign-in.
- Bundle Vazirmatn, add a mobile navigation drawer, and document the visual system in DESIGN.md.

## 0.1.0

- Same-site Dexo dashboard and Dexo-styled WordPress login.
- Orders, private notes, tracking codes and printable packing slips.
- Catalog search and regular price and inventory updates.
- Dedicated orders, warehouse and catalog roles.
- English and Persian interfaces and a documented extension API.
